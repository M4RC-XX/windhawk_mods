# 🦅 [M4RC-XX] Windhawk Mods Collection

[![Windhawk](https://img.shields.io/badge/Windhawk-Mods-blue?logo=windows&style=flat-square)](https://windhawk.net/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A collection of custom C++ mods for [Windhawk](https://windhawk.net/), the customization platform for Windows. These mods are designed to tweak, enhance, and optimize various aspects of the Windows UI and system behavior.

## 🚀 How to Use

### Install locally from Source
If you want to test these mods, use a pre-release version, or tweak the code yourself:
1. Open Windhawk and click on **"Create a new mod"** in the top right corner.
2. Delete the default template code.
3. Copy the raw C++ code (`.cpp`) from the mod you want in this repository.
4. Paste it into the Windhawk editor.
5. Click **Compile** and then **Save**.
